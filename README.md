# Studio HASH iNf Lk — Website Starter

A responsive, English-first static website starter for GitHub Pages.

## Included
- Premium dark/purple homepage
- Separate brand pages for iNfpirex, iNfyzora, iNframex and iNfysona
- Replaceable sample SVG logos in `assets/logos/`
- Graphics portfolio placeholders
- Software product cards with disabled pre-release downloads
- iNframex gray-scale / inactive booking and package placeholders
- iNfysona audio preview and WhatsApp inquiry form
- FAQ, contact, terms, privacy and copyright pages
- Responsive mobile navigation and reduced-motion support

## Replace the sample logos
Open `assets/logos/` and replace the sample files with your official logos. The simplest option is to keep the same filenames and SVG format:
- `main-logo.svg`
- `infpirex-logo.svg`
- `infyzora-logo.svg`
- `inframex-logo.svg`
- `infysona-logo.svg`

If your logo is PNG or WEBP, update the matching `src` references in the HTML files and the favicon links. Prefer transparent PNG or SVG. Keep a backup of the sample files first if you want them later.

## Add graphics projects
1. Add artwork images to `assets/images/projects/`.
2. Replace the artwork placeholders in `pages/graphics.html` or extend `data/projects.json`.
3. Use optimized images and add descriptive alt text.
4. Only publish artwork you have permission to display.

## Add software
Edit `data/software.json` and the cards in `pages/software.html`. Keep download controls disabled until the release is real. Before release, add a valid download URL, version, release date, file size, platform requirements, license details and SHA-256 checksum.

## Add music previews
1. Put your audio preview in `assets/audio/`.
2. Update the audio source in `pages/music.html`.
3. Replace sample cover artwork if desired.
4. Only publish music/audio you own or have permission to use.

The iNfysona order form opens WhatsApp with a prefilled inquiry. It does not store submissions in a database or confirm an order automatically.

## GitHub Pages deployment
1. Create a GitHub repository, for example `studio-hash-inf-lk`.
2. Upload the contents of this folder to the repository root (not the outer ZIP folder).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for the deployment link to appear in the Pages section.

For a project repository, the website URL usually looks like `https://YOUR-USERNAME.github.io/studio-hash-inf-lk/`. Replace `YOUR-USERNAME` with your GitHub username. If you use a custom domain later, configure it in GitHub Pages settings.

## Important notes
- GitHub Pages is static hosting. It does not provide a private admin dashboard, database, or server-side form processing by itself.
- The contact links and WhatsApp inquiry flow work without a backend. To store contact form submissions, bookings, or customer reviews, connect a trusted form service or backend and update the privacy policy accordingly.
- The Terms and Privacy pages are starter drafts, not legal advice. Review and adapt them before treating them as final legal policies.
- All logos included here are sample placeholder designs. Replace them with your official logos before launch.
- iNframex is intentionally shown as inactive; its buttons are disabled.
